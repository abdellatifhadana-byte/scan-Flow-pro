The user wants to build a full-stack application named ScanFlow Pro to automate the processing of multi-page PDF files.

**PRODUCT REQUIREMENTS:**
1.  **File Upload:** A page to upload multiple PDF files, delete them, and assign a special name () to each file for naming the final output.
2.  **ROI Editor:** For each file, the user must be able to:
    *   Define a Region of Interest (ROI) for a keyword and a code on a page preview.
    *   The ROI coordinates should be saved as percentages to be resolution-independent.
    *   The user can select a keyword from a list or add a new one.
    *   The system should support auto-detection for keywords and codes.
3.  **Analysis Engine:**
    *   A progress page showing the status of the analysis for each file.
    *   The backend should perform OCR (Tesseract or EasyOCR) on each page within the defined ROI.
    *   It must find the specified keyword and then extract the code that follows it. The code is numeric, 4-8 digits.
    *   Handle dependent pages (e.g., a main page has 2 subsequent pages associated with it).
4.  **Smart Merging & Naming:**
    *   Pages (from different original files) that share the same extracted code should be grouped.
    *   The system should create a single merged PDF file for each unique code.
    *   Individual pages and merged files must follow a specific naming convention:  for single pages and  for merged files.
    *   All outputs for a given code should be stored in a dedicated folder, e.g., .
5.  **Advanced Code Validation (Confidence System):**
    *   Since codes are repeated across multiple files (e.g., page 1 of file A, B, and C have the same code), the system should implement a confidence score for each OCR extraction.
    *   The code with the highest confidence (e.g., 100%) for a specific page position (e.g., page 1) should be considered the correct code for that position across all files.
6.  **Interactive Results Page:**
    *   Display all processed pages in a detailed, editable table.
    *   The table should show: a thumbnail of the ROI, original file name, page number, extracted code, confidence score, and the final output file name.
    *   Users must be able to edit the extracted code and output name directly in the table.
    *   Provide filtering and sorting capabilities.
    *   Include action buttons to:
        *   Select specific pages and merge them into a single file.
        *   Create individual output files for selected pages.
        *   Merge All based on the grouping logic.
