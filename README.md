# ScanFlow Pro 🚀

نظام معالجة وتحليل ملفات PDF الاحترافي مع تقنية OCR المتقدمة

## 🌟 المميزات الرئيسية

✅ **معالجة ملفات PDF متقدمة**
- دعم الملفات الكبيرة (أكثر من 50 صفحة)
- معالجة متعددة اللغات (العربية، الفرنسية، الإنجليزية)
- استخراج الأكواد الرقمية (4-8 أرقام) تلقائياً

✅ **تقنية OCR قوية**
- Tesseract OCR للدقة العالية
- معالجة صور متقدمة (CLAHE, Denoising, Thresholding)
- دعم التدوير والقص

✅ **واجهة مستخدم احترافية**
- رفع ملفات بالسحب والإفلات
- محرر ROI تفاعلي
- تتبع التقدم في الوقت الفعلي
- معاينة وتحميل النتائج

✅ **التجميع الذكي**
- تجميع الصفحات حسب الكود
- دعم الصفحات التابعة
- تسمية تلقائية منظمة

## 🚀 كيفية الاستخدام

### 1️⃣ رفع الملفات
- اسحب ملفات PDF أو انقر للاختيار
- أدخل الاسم (nom) للتسمية

### 2️⃣ إعداد ROI
- اضغط "إعداد" لكل ملف
- حدد الكلمة المفتاحية
- ارسم منطقة الكود والكلمة المفتاحية
- حدد عدد الصفحات التابعة

### 3️⃣ بدء التحليل
- اضغط "بدء التحليل"
- راقب التقدم

### 4️⃣ استعراض النتائج
- شاهد الأكواد المستخرجة
- معاينة وتحميل الملفات

## 🛠️ التقنيات المستخدمة

**Backend:**
- FastAPI
- PyMuPDF
- OpenCV
- Tesseract OCR
- MongoDB

**Frontend:**
- React 19
- Shadcn UI
- Tailwind CSS
- Axios

## 🔧 التشغيل

الخوادم تعمل تلقائياً عبر Supervisor:

```bash
# التحقق من الحالة
sudo supervisorctl status

# إعادة التشغيل
sudo supervisorctl restart backend
sudo supervisorctl restart frontend
```

## 📊 API Endpoints

- `POST /api/upload` - رفع ملف
- `POST /api/files/{file_id}/config` - حفظ إعدادات
- `POST /api/analyze` - بدء التحليل
- `GET /api/results/{analysis_id}` - الحصول على النتائج
